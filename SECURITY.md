# Security Policy

If you find a security issue in Easy Upload, please report it privately before opening a public issue.

Suggested report contents:

- affected version or commit
- storage backend in use
- reproduction steps
- impact assessment
- any logs or request samples that help explain the issue

This repository is an early-stage open-source and portfolio project, so response times are best-effort rather than guaranteed.

Security issues include, for example:

- authentication bypass
- unauthorized access to upload state or stored data
- path traversal or unsafe file handling
- request smuggling or protocol-level abuse with clear security impact
